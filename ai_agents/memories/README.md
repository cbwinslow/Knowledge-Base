# AI Agent Memories

This directory stores memories and learnings from AI agents.

## Format

Each memory file should follow this naming convention:
- `memory_YYYYMMDD_HHMMSS.md` for timestamped memories
- `[topic]_memory.md` for topic-specific memories

## Content Structure

```markdown
# Memory Title

**Date:** YYYY-MM-DD
**Agent:** [Agent Name/Type]
**Context:** [Brief context]

## Content

[Memory details here]

## Tags

- tag1
- tag2
- tag3
```

## Examples

- `memory_20251022_140000.md` - General timestamped memory
- `python_debugging_memory.md` - Topic-specific memory
- `project_x_learnings.md` - Project-specific learnings
