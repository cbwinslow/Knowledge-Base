## Content

When working with Python projects:
1. Always use virtual environments to isolate dependencies
2. Use requirements.txt or pyproject.toml for dependency management
3. Follow PEP 8 style guidelines for code formatting
4. Write docstrings for all functions and classes
5. Use type hints for better code clarity
6. Test your code with pytest or unittest
