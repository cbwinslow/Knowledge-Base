# AI Context Documentation

This directory contains documentation specifically formatted for AI agent context.

## Purpose

Documentation in this directory is:
- Structured for easy AI parsing
- Includes rich metadata for context understanding
- Organized by topic and complexity
- Optimized for AI agent consumption

## Structure

Content is organized to provide AI agents with:
- Clear context and background
- Working examples with explanations
- Best practices and patterns
- Common pitfalls and solutions

## Usage

AI agents can reference these documents to:
- Understand specific technologies
- Learn best practices
- Find working examples
- Get context for code generation

## Content Generation

Content is automatically generated and organized by:
- `download_documentation.py` - Downloads documentation
- `ingest_knowledge.py` - Processes and indexes
- `label_content.py` - Labels and categorizes

## Maintenance

This directory is automatically maintained by the documentation management system. Content is updated when the download and ingestion scripts are run.
