# Documentation Library

The `docs/` directory now collects the primary documents that were previously spread across the repository. Each subdirectory groups related files so contributors can quickly find what they need.

## Structure Overview

- **overview/** – High-level entry points and navigation guides.
- **setup/** – Environment provisioning, deployment, and shell configuration guides.
- **architecture/** – Implementation rules, architectural references, and workflow descriptions.
- **guides/** – Usage guides and improvement playbooks for the knowledge base.
- **agents/** – Agent-focused references, workflows, and related prompt packs.
- **projects/**
  - **ai_blackjack_poker/** – Planning and analysis documents for the real-time card assistant initiative.
  - **cloud_curio/** – Cloud Curio reference material, installer notes, and templates.
- **resumes/** – Resume and reference documents kept for profile management.
- **metadata/** – Generated indexes and supporting metadata (for example, `dynamic_toc.json`).

Additional knowledge libraries remain available at the repository root:

- **documentation/** – The existing comprehensive documentation system with guides, examples, and research.
- **master_documents/** – Legacy setup bundles, reports, and configuration archives.
- **TABLE_OF_CONTENTS.md** – The historical dynamic index; links now point to the reorganized file locations.

Use this index alongside `docs/overview/README.md` for recommended starting points and navigation tips.
